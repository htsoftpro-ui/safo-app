# توسيعة اكتشاف النماذج

تمت إضافة مكتبة نماذج مجانية ومحلية تضم 15 مسارًا أوليًا تشمل Qwen وDeepSeek وLlama وMistral وGemma وPhi وAya وGLM وKimi وOllama المحلي.

أضيف زر «اكتشاف تلقائي» داخل لوحة النماذج. عند الضغط، يحاول المتصفح قراءة كتالوج OpenRouter العام، يرشح المعرّفات المنتهية بـ `:free`، يدمجها مع الكتالوج المحلي، ثم يعرض أول ثمانية نماذج حسب الترتيب. عند فشل الشبكة، يعود تلقائيًا إلى الكتالوج المحلي الآمن بدل تعطيل الواجهة.

اختبار المتصفح أكد ظهور زر الاكتشاف، بدء حالة «جارٍ الاكتشاف»، وظهور سجل يوضح فحص OpenRouter وHugging Face والنماذج المحلية. لا توجد مفاتيح API داخل الواجهة.

ملاحظة مهمة: مجانية النماذج الخارجية مرتبطة بسياسة المزود وحصته الزمنية، لذلك لا يصح ضمان مجانية غير محدودة. المسار المحلي عبر Ollama هو الخيار المجاني الدائم بعد تنزيل النماذج على جهاز المستخدم.
