# شاعر — استوديو تأليف الأغاني العربية

واجهة عربية تجريبية مستقلة داخل مستودع صفو، صُمّمت لتجسيد تجربة وكيل تأليف الأغاني والشعر العربي من الفكرة إلى النص المعتمد.

## ما تم تنفيذه

تتضمن الواجهة مسارًا بصريًا واضحًا لفهم الطلب، إنشاء `MeterCard`، استدعاء المعرفة، توليد المسودة، فحص العَروض، ثم الإصلاح وإعادة القياس. كما تعرض بطاقةً للبحر والتفعيلات والروي والقافية وبنية الأغنية وقابلية الغناء، إلى جانب ترتيب نماذج مجانية متعددة مع تحويل احتياطي.

يعمل زر التوليد حاليًا كنموذج تفاعلي للواجهة، فيحاكي المراحل ويعرض الانتقال إلى حالة «موزونة ومعتمدة». هذا يحافظ على سلامة المستودع الحالي ويعطي أساسًا قابلًا للربط مع backend حقيقي.

## المعمارية المقترحة للربط الفعلي

يُفضّل عدم استدعاء مزودي النماذج من المتصفح مباشرة. بدلًا من ذلك، ينفذ الخادم مسارًا واحدًا باسم `POST /api/shaer/generate`، ويبني بطاقة الطلب ثم يمررها إلى موجه النماذج. يبدأ الموجه بالنموذج الإبداعي المتاح، وينتقل تلقائيًا إلى نموذج الإصلاح أو الفحص عند فشل المهلة أو انخفاض النتيجة.

بعد التوليد، يمر كل سطر عبر محلل عربي حتمي يطبّع الحروف، يحدد المقاطع، يطابق التفعيلات، ويقيس الروي والقافية. لا يُعتمد النص إلا بعد اجتياز الوزن والقافية وقابلية الغناء، أو بعد عدد محدد من دورات الإصلاح.

| الطبقة | الدور | حالة الواجهة |
|---|---|---|
| فهم الطلب | استخراج الغرض واللهجة والبنية والموضوع | ممثل بصريًا |
| MeterCard | تثبيت البحر والروي والقافية والإيقاع | ممثل بصريًا |
| RAG | استرجاع معرفة البحور والمقامات واللهجات | ممثل بصريًا |
| Model Router | اختيار نموذج إبداعي ثم fallback | معروض بأسماء النماذج |
| محرك العروض | فحص كل سطر حتميًا | نتيجة موزونة تجريبية |
| Repair Loop | إعادة صياغة السطور المخالفة مع الحفاظ على المعنى | ممثل في مسار التفاعل |
| الغناء | تقييم طول النفس والنبر وقابلية النطق | معروض في بطاقة التأليف |

## التشغيل المحلي

يمكن فتح `index.html` مباشرة، أو تشغيله عبر خادم ملفات ثابت:

```bash
cd shaer-app
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الخطوة التالية للإنتاج

يلزم إضافة backend آمن، ومزودات النماذج التي يختارها صاحب المشروع، وقاعدة معرفة عربية، ثم استبدال المحاكاة الموجودة في الزر بطلب فعلي إلى endpoint التوليد. ينبغي حفظ مفاتيح المزودات في متغيرات بيئية على الخادم، مع إبقاء fallback المحلي أو النصي حتى لا تتوقف الخدمة عند تعطل مزود واحد.
