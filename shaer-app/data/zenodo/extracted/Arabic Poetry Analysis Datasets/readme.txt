# About Data collection methodology
The data collection methodology is explained in readme files for each specific resource.

# File formats
Text files are in comma separated value format (CSV) or Excel format (xlsx). Files are encoded in UTF8.
Figures are provided in Encapsulated PostScript format (EPS) or Portable Network Graphics (PNG) format.
