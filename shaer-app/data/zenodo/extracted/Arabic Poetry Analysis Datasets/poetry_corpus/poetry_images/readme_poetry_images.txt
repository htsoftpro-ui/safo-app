# About the Dataset
This dataset contains 104 visualizations of Arabic poems, provided as PNG images.

# Folders
- distinct_colors: Contains images where each pattern has a distinct color.
- shared_colors: Contains images where patterns share the same color based on their syllabic quantity, with varying opacity for each pattern.

# Filename Mapping
The mapping between the image filenames, poets, and poems is available in 'poet_poem_image.csv' and 'poet_poem_image.xlsx'.

# Data Collection Methodology
Python's Matplotlib library was used to convert the poem data into images.

# File Formats
The images are provided in PNG format (Portable Network Graphics).
