# About the Dataset
This dataset "patterns_shared_colors.xlsx" contains colors where patterns having the same syllabic quantity share the same color with variation of the opacity.

# Data Collection Methodology
The colormap "viridis" in Python library matplotlib has been used for pattern colors.

# Description of the data
Column name: PTRN
Column description: pattern syllabic sequence
Column data type: Categorical

Column name: Q
Column description: pattern's syllabic quantity
Column data type: numeric

Column name: OPACITY
Column description: color opacity (always 1)
Column data type: numeric

# File Formats
The colors data is provided in an Excel file.
