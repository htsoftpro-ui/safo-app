# About the Dataset
This dataset "patterns_distinct_colors.xlsx" contains patterns where each pattern has its own distinct color. 

# Data Collection Methodology
Patterns colors are chosen manually.

# Description of the data
Column name: PTRN
Column description: pattern syllabic sequence
Column data type: Categorical

Column name: Q
Column description: pattern's syllabic quantity
Column data type: numeric

Column name: COLOR
Column description: color in hexadecimal code
Column data type: Categorical

Column name: OPACITY
Column description: color opacity (always 1)
Column data type: numeric

# File Formats
The colors data is provided in an Excel file.
