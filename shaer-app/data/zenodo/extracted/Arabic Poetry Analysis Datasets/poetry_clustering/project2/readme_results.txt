# About Dataset
This dataset contains the final clustering assigment of poems to clusters.

# About Data collection methodology
This dataset contains the final clustering results obtained by Python experiments.

# Description of the data. More details are described in the article itself.
Column name: Poet
Column description: name of the poet
Column data type: Categorical

Column name: Poem
Column description: name of the poem
Column data type: Categorical

Column name: Data source
Column description: file containing poem's data
Column data type: Categorical

Column name: Distribution across columns
Column description: distribution of the syllabic quantity acrosse columns
Column data type: Numeric

Column name: Distribution across rows
Column description: distribution of the syllabic quantity acrosse rows
Column data type: Numeric

Column name: Distribution across cells
Column description: distribution of the syllabic quantity acrosse cells
Column data type: Numeric

Column name: Positions across columns
Column description: how the sylabic quantities are positioned across the columns relative to the number of rows.
Column data type: Numeric

Column name: Positions across rows
Column description: how the quantities are positioned across the rows relative to the number of columns
Column data type: Numeric

Column name: best_cluster
Column description: cluster assigned to the poem
Column data type: Numeric

# Files formats
These results are provided in an Excel file.
