# مصادر قاعدة شاعر الموسعة

تمت إضافة طبقات معرفة مولّدة ومهيكلة للعروض والقافية والنطق واللهجات والمقامات والإيقاعات وبنية الأغنية.

| المصدر | الترخيص/الحالة | الاستخدام داخل شاعر |
|---|---|---|
| [Arabic Poetry Analysis Datasets](https://doi.org/10.5281/zenodo.12755351) | CC BY 4.0 | مضمّن محليًا للتحليل العروضي مع النسبة |
| [Diwan](https://github.com/NoorBayan/Diwan) | مستودع MIT، حقوق النصوص الأصلية تحتاج تحققًا | فهرس مرجعي فقط |
| [AraPoems](https://doi.org/10.7910/DVN/PJPWOY) | CC BY-NC 4.0 | فهرس بحثي فقط، لا يضمّن في نشر تجاري |
| [Habibi](https://aclanthology.org/2020.lrec-1.165/) | متاح للبحث، شروط إعادة التوزيع يجب مراجعتها | مرجع لتصنيف اللهجات وبنية الأغنية |

## ملاحظة

الهدف ليس نسخ «كل الشعر العربي» بلا تمييز، بل بناء معرفة قابلة للتدقيق: قواعد عروض، فهارس، أمثلة مرخصة، ومخططات استرجاع. هذا يجعل شاعر أقوى وأقل عرضة لتسريب نصوص محمية أو خلط اللهجات.
