# سجل اختبار مركز الأوامر

## النطاق

تمت إضافة مركز أوامر ذكي داخل الاستوديو يسمح بلصق أغنية أو شعر أو كتابة طلب طبيعي، ثم اختيار وضع التنفيذ أو الضغط على أحد الأوضاع السريعة.

## الأوضاع المضافة

| الوضع | الوظيفة |
|---|---|
| تحويل إلى خليجي عامي سلس | إعادة صياغة النص بلهجة خليجية قريبة من السامري مع الحفاظ على الجو الغزلي |
| إعادة الصياغة | تحسين الصور واللغة مع الحفاظ على المعنى |
| الاستكمال | إضافة مقاطع بنفس الجو والقافية |
| كتابة شعر جديد | تحويل فكرة قصيرة إلى نص شعري |
| بناء أغنية كاملة | مقدمة، كوبليه، مذهب، جسر، خاتمة |
| إصلاح الوزن والقافية | بطاقة عَروضية وصياغة مقترحة قابلة للغناء |
| الاختصار والتوسعة | التحكم في طول النص وبنيته |

## نتيجة الاختبار

تم تشغيل وضع «تحويل إلى خليجي عامي سلس» على النص «يا مكحّل في الرياض». ظهرت نتيجة جديدة تضمنت مذهبًا خليجيًا وصورًا مرتبطة بالرياض، مع حالة «اكتمل التنفيذ — النتيجة قابلة للتعديل» وظهور لوحة النتيجة أسفل مركز الأوامر.

## الحدود الحالية

التوليد الحالي داخل الواجهة هو fallback محلي مضمون النتائج. ربط النتيجة بنموذج خارجي فعلي يتطلب Backend آمنًا يمرر الطلب إلى المزود ويعيد النص إلى الواجهة دون كشف مفاتيح API.
