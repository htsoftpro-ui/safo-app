# Yemen Offline Map

تطبيق خريطة تفاعلية لليمن مبني على React وMapLibre GL JS وPMTiles. يعمل بأسلوب local-first، ويستخدم أرشيف Vector Tiles محليًا بدل خدمات خرائط خارجية وقت التشغيل.

## التشغيل

```bash
pnpm install
pnpm dev
```

لبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
pnpm preview
```

## مصدر البيانات

الملف `public/data/yemen-shortbread-1.0.pmtiles` هو أرشيف Shortbread مبني من استخراج اليمن الرسمي من Geofabrik، ويحتوي على بيانات OpenStreetMap المرخصة بـ ODbL. لا يستخدم التطبيق Google Maps أو Google Earth أو Geocoding API مدفوعًا. يظهر إسناد OpenStreetMap وGeofabrik داخل الواجهة.

تُقرأ PMTiles عبر HTTP Range Requests وMapLibre WebGL؛ لذلك لا تُحمّل كل عناصر اليمن إلى الذاكرة دفعة واحدة. يتم جلب نطاقات الأرشيف المطلوبة فقط، وتُخزّن الاستجابات المحلية عبر Service Worker بعد أول استخدام.

## البيانات المتدرجة

تعرض الحزمة الحدود والأماكن والمياه والأراضي والطرق والمباني وفق مستويات التكبير التي توفرها طبقات Shortbread. لا يُنشئ التطبيق أي طرق أو مبانٍ غير موجودة في المصدر. بعض طبقات الشوارع والمباني التفصيلية تبدأ من مستويات التكبير العليا في استخراج Shortbread؛ للحصول على تغطية طرق أدق في المستويات المتوسطة، أعِد بناء الحزمة من PBF مخصص باستخدام خط أنابيب تحويل Vector Tiles مناسب.

## التضاريس

الكود يدعم Terrain Rendering وHillshade من خلال Raster DEM محلي. لن يطلب التطبيق ملفات ارتفاعات غير موجودة؛ لا يُفعّل Terrain تلقائيًا إلا عند وجود `public/data/dem/manifest.json` وراستر `dem/{z}/{x}/{y}.png` بترميز Terrarium. هذا يمنع أخطاء التشغيل Offline ويجعل إضافة حزمة DEM خطوة مستقلة قابلة للتحقق من المصدر والترخيص.

## البحث والتفاعل

تتضمن الواجهة فهرسًا محليًا في `public/data/search-index.json` للمحافظات والمدن والموانئ والجزر والمعالم الأساسية، مع fallback فوري عند بدء التشغيل. يدعم البحث العربي والمرادفات المحددة في الفهرس، ثم انتقالًا سلسًا إلى الموقع. تتضمن الواجهة كذلك تحديد الموقع، إعادة عرض اليمن، Fullscreen، Dark Mode، تحكمًا فعليًا في طبقات الطرق والمباني والمياه والأماكن، أدوات التكبير، النقر على المعالم، ودعم MapLibre للسحب والتكبير باللمس والعجلة وPinch Zoom.

## Offline

بعد أول تحميل ناجح، يسجّل التطبيق `public/sw.js` ويخزّن ملفات الواجهة وطلبات البيانات المحلية. لتوزيع نسخة Offline كاملة، يجب توزيع مجلد `public/data` مع ملف PMTiles وأي حزمة DEM اختيارية. لا تتطلب الخريطة اتصالًا بخدمة خرائط خارجية أثناء التشغيل.

## الاختبار

```bash
pnpm check
pnpm build
```

يجب اختبار النسخة المبنية عبر خادم HTTP محلي، لأن PMTiles يحتاج HTTP Range Requests. اختبار `file://` المباشر غير مناسب. راجع `../../docs/map-browser-test.md` لسجل الاختبارات والملاحظات الحالية.
